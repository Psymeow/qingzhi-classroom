# 课堂分析报告 Word（完整版）· 目标规格与验收

> 适用对象：线上项目（地址待部署后填写）的报告导出实现者。
> 性质：把现有导出从"摘要级"提升到"可追溯的课堂观察报告"，与已验收样张同量级。
> 原则：只改报告组装与文案生成，不改评分模型、权重、档位判定与报告数据结构。

---

## 0. 目标一句话

同一课例、同一标准、同一批材料，"完整版"必须做到三点：**章节不缺、每条结论有出处、全文量级与样张相当**。样张量级基线见第 6 节。

---

## 1. 固定章节结构（完整版）

顺序固定，一级标题固定为 7 个，每个一级标题强制新起一页，且标题不得落在页面底部（标题与后文同页）：

```
封面
一、一眼看这课
二、五维拆开看
三、每条分的出处
四、课堂现场与材料
附录 A　评分档位说明
附录 B　理论依据与参考文献
```

### 1.1 封面（独立成页，首页无页码）

必须出现：报告标题、课例名、报告版本（精简版/完整版）、学校、班级、授课教师、报告生成人、评价标准名称与版本、生成日期、生成时间、报告状态（AI 生成 / 人工终裁）、使用范围声明。

规则：
- 报告生成人取当前导出账号的姓名；取不到写"未填写"，**不得输出字段名本身**，不得留空下划线。
- 课例名按原标题显示一次，不要在已有书名号外再套一层。
- 学校、班级在同一份文档内只能有一个值，封面与页脚必须一致。

### 1.2 第一章 一眼看这课

必须出现：
1. 章节导语：一句话说明本章回答什么问题。
2. 五维加权综合得分（0–100，保留一位小数）、综合等级、换算说明（满分 100，由五维加权平均 ×10）。
3. 情智双侧速读表：认知素养（D2）、情感素养（D3）、关系形态；表后接一句关系形态解读，并明确"这是重心位置，不是好坏判断"。
4. AI 教学评语：≤200 字，必须点名 1 个优势环节与 1 个待改环节。
5. 课堂亮点 4 条：每条 ≤60 字，须包含可核对的事实（环节名、学生行为、材料）。
6. 改进建议 4 条：每条须含"做什么 + 对谁 + 用多久 + 预期变化"，不得只写方向。
7. 情智关系解读：说明情感投入如何支撑或阻滞认知推进。
8. 下一节课可以这样改 3 条：编号、时长、操作步骤。
9. AI 生成声明：仅作参考、不改变评分、可人工终裁后重新生成。
10. 若有 AI 解读自动补齐，须标注补齐结果（补齐几个域、是否已保存）。

### 1.3 第二章 五维拆开看

必备四个部分，缺一不可。

**(1) 五维评分总表**，列固定为：维度 / 权重 / 得分 / 等级 / 指标覆盖（已评÷总数）/ 待复核。

**(2) 逐维区块**（每个维度一块，共 5 块），每块必须有：
- 维度名 + 得分 + 等级（作为小标题）
- 二级指标表：二级指标 / 得分 / 评分状态（已评、不可评、待复核要能区分）
- 关键证据 2–4 条：每条为"时间码 + 说话人（或材料出处）+ 原话摘引（≥10 字）+ 这条证据支撑了什么判断"
- 理论依据：1–2 句，说明该维度为何这样设、引用哪条文献（与附录 B 对应）
- AI 维度解读 ≥300 字，按四段写：这个维度看什么 / 这课判成几分及其原因 / 证据落在哪里 / 下一步怎么改

**(3) 课型专属要点**
- 概览表：课型均分 / 折算百分制 / 已评要点 / 课型来源。课型来源须写明是"自动识别（置信度 x%）"还是"人工指定"；人工指定时不显示置信度。
- 要点表列固定为：编号 / 要点 / **判定标准** / 得分 / 等级。判定标准列不可省。
- 逐要点"判定依据与打分理由"：每个要点 ≥80 字，含观察事实、判定理由、引用出处。要点未评的要写明原因。

**(4) 认知与情感观察点**
- 总体覆盖表：观察点已评 / 观察点总数 / 认知侧 / 情感侧。
- 认知侧、情感侧各一张指标均分表。
- 认知侧、情感侧各一段 AI 内涵解读（≥300 字）。
- **观察点明细表**：每个二级指标一张，列固定为 观察点 / 定义与打分归因 / 依据来源 / 得分 / 状态。观察点总数不得少于 57 个（认知侧 + 情感侧全量），不可评的必须保留行并写明"本次未提交 XX 材料，故不可评"，且已从均分中剔除。禁止只给均分不给逐点归因。

### 1.4 第三章 每条分的出处

- 章节导语一句。
- 按维度分块，块标题写"序号 + 维度名 + 得分"。
- 证据按来源分组：课堂实录 · 师生原话 / 学生任务单 · 学生作答 / 观察员记录 · 听课笔记 / 教学设计 · 课前教案 / 人工标注。每组至少 1 条。
- 每条证据必须包含：时间码（mm:ss）、说话人或出处、原话/原文摘引、指向的判断。仅有一句概括不算证据。

### 1.5 第四章 课堂现场与材料

- 章节导语一句。
- 座位与互动关系：布局说明（几排几列、座位朝向）+ 角色图例（角色名与符号）+ 排×列网格（空位显式标"空位"，有人的位置显示**姓名 + 简短角色**）+ 互动连线清单。
- 互动清单列固定为：序号 / 发起方 / 指向 / 类型 / 方向 / 时间 / 说明。发起方与指向必须是学生姓名，不允许出现座位 ID。
- 课堂现场标注统计表：座位标注学生数 / 互动连线数 / 关键事件数。
- 材料与数据覆盖表：材料类型 / 是否提供 / 引用证据条数 / 说明。
- AI 参与情况表：AI 项 / 状态 / 说明。状态与说明必须一致：标"成功"就不得同时写"返回内容异常"。

### 1.6 附录 A 评分档位说明

- 读取**课例绑定的评价标准**中的档位（名称、0–10 区间、0–100 区间、描述），不得写死通用五档。
- 覆盖本课实际用到的全部档位词（各维度可能有各自的档位命名，如"未融合/较融合"与"基本显现/表现良好"），必要时按维度分组列出并标明适用维度。
- 标准数据缺失或字段不全时：整体回退通用五档，并在表前写明"以下为系统通用五档，未取到绑定标准档位数据"，不得静默替换。

### 1.7 附录 B 理论依据与参考文献

- 理论依据段落 + 编号参考文献（按作者字母序或引用序统一一种）+ 悬挂缩进。
- 文末保留方法学说明与报告性质声明（教学改进用途、不用于人事评价、AI 可能有偏差、可人工终裁）。

## 2. 文案质量标准

**硬规则：结论必须绑定依据。**

每条涉及判断的文字（得分、等级、亮点、改进建议、课型判定、观察点归因、关系形态）都要能回答"凭什么"，写法建议：

```
时间码 + 说话人/材料 + 原话摘引 + 判断
例：12:40 教师追问"你为什么先提公因式？"，学生回答"提取后括号里更简单"
    → 记为合理质疑/择优优化得分的依据。
```

- **缺材料时**：写"本次仅提交 XX，未提交 XX，该观察点不可评"，并从均分中剔除；不得用"表现较好/有待加强"这类无依据概括顶替。
- **证据不足时**：写"依据不足，暂按 X 分判定，建议补充 XX 材料后复核"，不得编造原话或时间码。
- **一致性**：同一事实（分数、等级、人数、互动条数、学校班级、课型来源）在全文中只能有一种说法。
- **信息密度**：单段 60–200 字；不允许连续 3 段只有形容词没有事实。
- **AI 解读**：统一四段式（看什么 / 判几分及原因 / 证据在哪 / 怎么改），禁止空泛总结。

## 3. 版式要求

| 项 | 要求 |
|---|---|
| 纸张 | A4 纵向 210×297mm |
| 页边距 | 上下 1100 twips，左右 1000 twips |
| 正文字体 | 中文宋体，西文 Times New Roman，12pt，行距 1.5 |
| 标题字体 | 黑体；一级 18pt，二级 14pt，三级 12pt |
| 表格字号 | 常规 10.5pt，密集表（观察点、互动清单）9pt |
| 封面 | 独立成页；首页不显示页码（页眉页脚首页留空） |
| 页眉（非首页） | 报告名 + "内部资料，仅用于教学改进" |
| 页脚（非首页） | 学校 · 班级　第 X 页 / 共 Y 页（使用页码字段，不手写数字） |
| 分页 | 每个一级标题前强制分页，标题 keepNext；表格行 cantSplit，避免跨页断裂 |
| 表号 | "表 N-M 表题"置于表格上方，N 为章号，M 为章内序号，全文连续不跳号 |
| 表格样式 | 表头底纹 + 斑马纹 + 固定列宽铺满版心，表头与数据列边界严格对齐 |
| 禁止 | 标题落在页底、表格跨页断裂、出现空白页、表号重复或缺失 |

## 4. 禁止项（出现任一条即判不合格）

1. 编造证据：虚构时间码、原话、学生姓名、材料名称。
2. 空表：只有表头没有数据，或用"—"整列填充。
3. 占位文案：`报告生成人`、`XX中学`、`＿＿＿＿`、"未命名未标注角色"作为最终呈现。
4. 未解析 ID：座位/互动中出现 `s_0_1`、`s_1_2` 这类内部标识。
5. 前后矛盾：AI 状态"已成功产出"同时写"返回内容异常"；封面学校与页脚学校不一致。
6. 结构缺失：缺逐维 AI 解读、缺观察点明细、缺判定标准列、缺指标覆盖列。
7. 档位错配：附录 A 与正文使用的档位名对不上，或用通用五档冒充绑定标准。
8. 同课不同分：同一课例重复导出分数不一致；如属模型随机性，必须在文档或元数据中记录模型名、版本与参数。

## 5. 验收清单（逐项勾选）

- [ ] 7 个一级标题齐全、顺序固定，全部新起页，标题未落页底
- [ ] 封面独立成页、首页无页码、无任何占位字段
- [ ] 页眉页脚存在，"第 X 页 / 共 Y 页"为字段而非死数字
- [ ] 五维总表 6 列（含指标覆盖）
- [ ] 5 个维度各具备：二级指标表 + 关键证据 + 理论依据 + AI 维度解读（≥300 字）
- [ ] 课型要点表含"判定标准"列，逐要点依据齐全（每点 ≥80 字）
- [ ] 观察点明细覆盖全量 57 点，不可评点有原因说明且已剔除均分
- [ ] 认知侧、情感侧各有 AI 内涵解读，各 ≥300 字
- [ ] 第三章证据按来源分组，时间码 ≥60 个、原话引号 ≥100 处（对齐样张量级）
- [ ] 座位网格显示姓名 + 角色；空位显式标注
- [ ] 互动清单发起方/指向均为姓名，无内部 ID
- [ ] 附录 A 读取绑定标准档位，覆盖本课实际档位词
- [ ] AI 参与情况状态与说明一致
- [ ] 全文无空表、无断裂表、无空白页、表号连续
- [ ] 全文总字数 ≥25,000（样张约 32,600）
- [ ] 同一课例连续导出两次，分数与关键统计一致（或已记录模型参数）

## 7. 可直接粘贴的开场指令（≤150 字）

> 这是对现有报告导出的**增量改造**：按《目标规格》把"完整版"补齐到 7 章固定结构，重点是逐维 AI 解读、观察点明细、逐条证据带时间码与原话、附录读绑定标准档位。不要改评分模型、权重、档位判定与报告数据结构，不要重建项目。先对照规格自检，再按验收清单逐项打勾。
